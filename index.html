REUSE BEFORE REPLACE

Before replacing a computer, see whether it can be improved.

An older computer is not automatically an unusable computer. Norlium can assess whether repair, an SSD or memory upgrade, software clean-up or a suitable Linux setup could extend its useful life.

Where appropriate, legitimate Linux and open-source software can provide a practical solution for web browsing, office work, email and everyday computing.

Upgrade when worthwhile. Replace when necessary. Reuse when practical.
