REUSE BEFORE REPLACE

Before replacing it, see whether it can be improved.

An older computer is not automatically an unusable computer. Norlium can assess whether repair, an SSD or memory upgrade, software clean-up, or a suitable Linux setup can give capable hardware more useful life.

Upgrade when worthwhile. Replace when necessary. Reuse when practical.
