# Norlium Technology — Website v1

Pre-launch static website prototype.

## Run locally
Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Before public launch
- Replace pre-launch contact placeholder with business contact details.
- Add final Privacy Notice and Terms from the Norlium Business Starter Pack.
- Select a secure form handler and update privacy/processors accordingly.
- Complete domain, business-name and legal identity fields.
- Test accessibility, mobile layout, links, form behaviour and browser compatibility.
- Add analytics only if needed and only after cookie/privacy implications are addressed.
